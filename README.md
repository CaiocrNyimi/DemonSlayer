# 🗡️ DemonSlayer

Um projeto em React Native + TypeScript inspirado no universo de Demon Slayer, com foco em estilização e prática de componentes visuais.

# 🚀 Funcionalidades

-Interface estilizada com CSS customizado.
-Estrutura modular para fácil manutenção.
-Tipagem forte com TypeScript.
-Projeto simples e para prática de front-end.

# 📂 Estrutura do Projeto

```
DemonSlayerCP/
├── assets/                # Arquivos estáticos (imagens, ícones, etc.)
├── src/                   # Código fonte principal
├── App.tsx                # Arquivo principal da aplicação
├── app.json               # Configurações do projeto
├── index.ts               # Ponto de entrada
├── package.json           # Dependências e scripts
├── package-lock.json      # Lock das dependências
├── tsconfig.json          # Configuração do TypeScript
└── .gitignore             # Arquivos ignorados pelo Git
```

# 🛠️ Tecnologias Utilizadas

-React Native
-TypeScript
-CSS

# 📦 Instalação e Uso

1. Clone o repositório:
```
  git clone https://github.com/CaiocrNyimi/DemonSlayer.git
```

2. Instale as dependências:
```
  npm install
```

3. Execute o app:
```
  npm start
```
